# A3 Private Pilot Record Template

Do not fill this tracked repository copy. Before an approved pilot, copy it to
the session's encrypted private folder outside the repository and complete the
private copy. Do not enter participant names, student numbers, consent-form
copies, or camera credentials.

Follow [`CLASSROOM_GROUND_TRUTH_PROTOCOL.md`](CLASSROOM_GROUND_TRUTH_PROTOCOL.md)
and [`ENGAGEMENT_LABEL_GUIDE.md`](ENGAGEMENT_LABEL_GUIDE.md). R1 and R2 use
separate private copies of
[`A3_REVIEWER_WORKSHEET_TEMPLATE.md`](A3_REVIEWER_WORKSHEET_TEMPLATE.md).
