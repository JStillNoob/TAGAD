# A3 Independent Reviewer Worksheet Template

Do not fill this tracked repository copy. The pilot coordinator must copy one
blank worksheet for R1 and another for R2 into separate encrypted private
review folders. Reviewers must not see predictions or each other's answers
until both worksheets are complete.

Use [`ENGAGEMENT_LABEL_GUIDE.md`](ENGAGEMENT_LABEL_GUIDE.md) and
[`CLASSROOM_GROUND_TRUTH_PROTOCOL.md`](CLASSROOM_GROUND_TRUTH_PROTOCOL.md).

name, camera credential, or school identifier.

## Allowed values

- **Camera:** `Front`, `Left`, or `Right`
- **Activity:** `Lecture`, `Reading`, `Note-taking`, `Individual task`,
  `Group work`, `Recitation`, or `Transition`
- **Visibility:** `Sufficient`, `Partial`, or `Insufficient`
- **Label:** `Engaged`, `Attentive`, `Confused`, `Bored`, `Disengaged`, or
  `Uncertain`

`Uncertain` maps to TAGAD's `Unclassified` outcome. A sample reference is a
random or window-local code prepared by the coordinator. It must not identify
or follow a participant across sessions.

## Reviewer completion check

- [ ] Every assigned sample has exactly one label.
- [ ] Weak, conflicting, or insufficient evidence remains `Uncertain`.
- [ ] Notes describe only visible behavior and lesson context.
- [ ] No names, identities, diagnoses, personality judgments, or predictions
      appear in the worksheet.
- [ ] The completed worksheet is saved only in the reviewer's private folder.
- [ ] The reviewer did not see the other reviewer's answers or pipeline output.
